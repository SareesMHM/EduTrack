# Training data

`sample_training.csv` is **synthetic**. It was generated by a script with a noisy rule
(low attendance, low average, falling scores and frequent lateness raise risk). It contains
no real student information, and a model trained on it only demonstrates the pipeline.

| Column | Meaning |
|---|---|
| attendancePct | % of counted days attended (excused days excluded) |
| avgScorePct | mean exam percentage |
| examsTaken | number of exams with a mark |
| scoreTrend | last exam % minus first exam % |
| lateRate | share of recorded days marked LATE (0-1) |
| at_risk | 1 if flagged at risk, else 0 |

Before using real data: get school/guardian approval, remove identifiers (only the five
numeric features leave the main database), check class balance across groups, and keep the
data out of git.
